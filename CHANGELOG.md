# Changelog

Changes of the `@meloduo/mcp` bridge, the guides and the skills. The tool list comes from the open Meloduo tab, so new studio features need no bridge update; their guides do.

## Unreleased

- Guides and server instructions for time signatures, the tempo map, the key of a pattern, audio warp and the sample slicer.
- Guides for audio clip fades, crossfades and reverse, batch calls, note slides, loudness matching and microphone recording by the user.
- Guides use the new preset, mode and style names.
- The development bridge waits for calls in flight before it restarts.
- `mcpName` and `mcp/server.json` for the MCP Registry.

## 0.3.0 (2026-11-28)

- Guides for chorus, flanger, phaser, gate, drive, guitar amp models and rigs.
- A post-punk genre guide and fixes from live agent tests.

## 0.2.0 (2026-11-25)

- The skill library: a router and four skills, with about 100 guides served by the new tool `get_guide`.

## 0.1.3 (2026-11-23)

- Security: the bridge trusts only the published app, marks tab activity and checks tool lists.
